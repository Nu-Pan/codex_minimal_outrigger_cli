# `app_spec`

## Summary
- cmoc 全体に共通するアプリ仕様を集め、ファイルの分類と責務、Codex の実行、入力と検索、状態管理、ログとエラー、feedback などの横断契約を確認する入口です。
- 個別サブコマンドの仕様へ進む前に、共通動作とコマンド固有動作の担当範囲を見分けるためにも使います。

## Read this when
- 複数のサブコマンドに関わる動作を変更・レビューするとき。共通仕様の根拠をここから確認できます。
- ファイル分類、Codex 呼び出し、プロンプト入力の受け渡し、session や run の状態、ログ、エラー、feedback の扱いなど、アプリ全体の契約を調べるとき。
- 共通ルールと個別コマンドのルールのどちらが判断を担うか調べるとき。

## Do not read this when
- 特定のサブコマンドの引数、事前条件、処理手順、固有の報告や終了条件だけを調べるときは、そのコマンドの仕様へ直接進んでください。
- builder に委譲された正確な prompt 文面や構築順序、アルゴリズム、schema を調べるときは、該当する実装仕様へ直接進んでください。

# `branch_model.md`

## Summary
- cmoc が session と run を管理する際の Git branch、commit、worktree の役割と相互関係を定義する。
- session/run の分岐元・merge 先、命名、対象範囲、run worktree の位置づけを確認するための入口。

## Read this when
- session branch と run branch の関係、分岐元や merge 先を確認するとき。
- fork/join に関わる commit の定義や、join が no-op となる条件を確認するとき。
- run worktree の役割や、管理対象 branch 上の変更範囲を判断するとき。

## Do not read this when
- 特定サブコマンドの手順、入出力、失敗時の動作を調べるときは、そのコマンドの仕様を直接読む。
- 実装方法やテストの内容を調べるときは、該当する実装またはテストを直接読む。

# `considered_alternative`

## Summary
- 不採用・廃止した方式ごとに、当時の目的、制約や懸念、判断、採用した代替の方向を記録する文書群。
- 権限制御、旧文書 routing、AI 改善案の自動反映、違反の事後検査、レビューや realization 作業の進め方などの判断履歴を確認する入口であり、現行仕様の定義ではない。

## Read this when
- 記録された候補を再検討するときや、同種の方式選択の背景と不採用理由を確認したいとき。
- 旧方式から現行方式へ移った経緯や、文書が案内する現行の正本をたどりたいとき。

## Do not read this when
- 現行挙動・制約の実装、検証、運用に必要な規範を調べるときは、対象領域の正本仕様へ直接進む。
- 記録された旧方式を現行動作として実装・運用する方法を調べるときは、その方式の記録ではなく現行の正本仕様を参照する。

## Read this when
- Python の型注釈、import、docstring、コメントなどの規約や、CLI・共通機能のコード構成を確認するとき。
- Python 環境や依存関係を準備・変更するとき、または文書検索資材のセットアップ条件を確認するとき。
- テストの対象や意味上の要件を設計・変更するとき。

## Do not read this when
- 製品の機能要件や挙動の正本を調べるときは、該当するアプリ仕様や実装を直接参照する。
- 既存テストの実行手順だけが必要な場合は、検査の選択・実行・完了判定を定める文書から確認を始める。
- テストの意味上の要件だけが必要な場合は、テスト実装規約を直接参照する。
