# `coding_rule.md`

## Summary
- cmoc実装のコーディング基準を定める。言語選択、識別子、型注釈、import、docstring、コメントの判断に使う。

## Read this when
- 実装や正本実装の書き方、またはコーディング上の許容範囲を決めるとき。
- 型注釈やdocstringの適用範囲、cwdを表す識別子、import、コメントやログの言語を判断するとき。

## Do not read this when
- 個別機能の要求、振る舞い、入出力仕様を確認するときは、その機能の仕様を直接読む。
- コード変更の検証手順だけを確認するとき。

# `design_rule.md`

## Summary
- CLI の入口とサブコマンド本処理の分担、および複数コマンドで使う共通機能の配置を定める設計規則。

- テストの意味上の要件や実行手順を確認するときは、テスト規則またはテスト実行手順を読む。

# `development_environment.md`

## Summary
- Python実行環境、仮想環境、依存関係、pip操作など、開発環境の準備と管理の規約を定める。
- 文書検索用資材のセットアップ、固定、検証、再構築の責務を扱い、資材の識別情報や検索動作の契約はそれぞれ専用の実装・仕様へ案内する。

## Read this when
- 開発環境を準備・再構築するとき、またはPython、仮想環境、依存関係、pipの扱いを確認・変更するとき。
- 文書検索の実行資材や依存関係のセットアップ、固定、検証、再構築を扱うとき。

## Do not read this when
- 構築済み環境で既存のtestや品質検査の選択・実行・完了判定だけを行うときは、test実行手順を定める文書へ進む。
- 文書検索の初期資材の正確な識別情報だけを確認するときは、その定義を持つ実装へ進む。
- 文書検索の入力や採点など、アプリケーション動作の契約だけを確認するときは、文書検索のアプリ仕様へ進む。

# `test_execution.md`

## Summary
- 構築済みの cmoc 開発環境を前提に、テストと品質検査の選択、実行、完了判定、結果報告の手順を定める。
- 現在の worktree で使う Python 環境の選択、検査前提の確認、変更時の検査と fresh な完了ゲート、実経路統合テストの扱いを確認する入口。

## Read this when
- 変更に対してどのテストや品質検査を実行するか、どの環境で実行するか、検査を完了と判定してどう報告するか決めるとき。
- 実経路統合テストを通常のテストと分けて実行し、完了条件を確認するとき。

## Do not read this when
- テスト実装の意味上の要件や実経路統合テスト自体の成立条件を確認するときは、テスト規約の正本を読む。
- Python 環境の新規構築、依存関係の追加、pip 操作を行うときは、開発環境の正本を読む。
- 型注釈や docstring の意味上の品質要件を確認するときは、コーディング規約の正本を読む。

# `test_rule.md`

## Summary
- realization test が検証する意味上の要件と対象範囲を定め、決定論的な制御ロジックと Codex CLI を伴う結合動作を扱う。
- 利用者向け CLI の実経路統合テストの成立条件と、Fake Codex CLI を使える範囲を示す。

## Read this when
- テストの期待動作や対象範囲を決める、または realization test の方針を見直すとき。
- 公開 CLI サブコマンドに対応する実経路統合テストを追加・変更するときや、テストの分類・実推論の扱いを確認するとき。
- Fake Codex CLI を使える条件を確認するとき。

## Do not read this when
- 構築済み環境での test・品質検査の選択、実行、完了判定、報告だけが必要な場合は、その実行手順の正本を読む。
- Python 環境の新規構築、依存関係の追加、pip 操作の条件だけが必要な場合は、開発環境の正本を読む。
