# 廃止した INDEX routing

旧方式は各階層のファイル・ディレクトリに概要と読む条件を付け、agent が読むべき本文を絞ることを目的としていた。生成、hash 更新、agent call 前の preflight、自動 commit、merge と差分検査の特例が結び付いて仕様が複雑になったため、cmoc 専用ベクトル検索へ置き換えた。旧方式との後方互換性は求めない。

現在の正本は `{{cmoc-root}}/oracle/doc/app_spec/document_search.md` の「cmoc 専用文書検索」であり、対象制御、同期、失敗、資源管理、および切替の受入条件を定める。

QMD SDK を包む案も検討した。厳密な対象制限には許可文書の投影と内部 guard による追加対応が必要となるため、cmoc が対象制御・同期・保存・MCP の中核責務を所有する方向を選んだ。QMD で厳密な制限が絶対に不可能だったという判断ではない。QMD は設計の参考とし、実行時依存には採用しない。
