# `oracle_and_realization_basic.py`

## Summary
- oracle と realization の基本概念を説明する文章を構築する関数。oracle file、realization file、uncategorised file の役割・下位概念・分類条件を、パス文脈に基づく見出し構造として返す。
- oracle と realization に関するプロンプト部品の内容を確認したいとき、またはこれらのファイル分類・責務を説明する基本知識の入口が必要なときに読む。

## Read this when
- oracle file と realization file の責務や、oracle doc/src/test・realization implementation/test/ancillary の区分を確認するとき。
- ファイルが oracle、realization、uncategorised のどれに分類されるか、その基本条件を確認するとき。

## Do not read this when
- 個別の oracle 文書や実装の詳細仕様を確認したいときは、対応する下位対象を直接読む。
- INDEX.md の生成規則やパス探索の詳細だけを確認する場合は、この基本概念の説明ではなく該当する規則文書を読む。
