## Summary
- oracle・realization・uncategorised file の基本的な役割と分類を agent 向け prompt 文面として組み立て、root の work-root 定義を渡す。

## Read this when
- agent 向けの基本説明に含める file 区分や役割、またはその prompt 文面の構成を変更するとき。
- この基本説明が使う work-root の placeholder の受け渡しを追うとき。

## Do not read this when
- file の役割や分類条件そのものを確認・変更するときは、意味仕様を定める oracle 文書を読む。
- 作業固有の権限、判断基準、引き継ぎなどを変更するときは、該当する個別 policy の定義を読む。
