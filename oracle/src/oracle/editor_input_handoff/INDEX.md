# `overwrite_input.json`

## Summary
- 対象は、cmoc のエディタ入力上書きツールに渡す入力形式を定義する JSON Schema です。対象 ID と上書き内容を指定するための、エディタ入力引き継ぎ処理の直接の参照先です。

## Read this when
- エディタ入力を特定の対象へ上書きするツール呼び出しの入力契約を確認するとき。
- 上書き対象の識別子と、書き込む内容の指定方法を確認するとき。

## Do not read this when
- エディタ入力上書き以外のツール入力や、エディタ入力引き継ぎ処理そのものの実装を確認したいとき。
- 対象 ID や内容の具体的な値ではなく、上位のワークフローや別の入出力契約を確認したいとき。
