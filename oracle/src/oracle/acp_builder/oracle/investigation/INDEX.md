# `launch_tui.py`

## Summary
- `cmoc oracle investigation` 用の完全プロンプトを構築し、oracle 調査担当を起動するための固定パラメータを定義する。
- ユーザー指示を調査用プロンプトへ組み込み、リポジトリルートを作業ディレクトリとして確定する。完全プロンプトは管理ログへ保存され、Codex CLI の TUI 起動に使用される。
- oracle ツリー内の関連ファイルを読み取り専用で調査する呼び出し経路を確認したい場合の入口であり、調査プロンプトの共通構成やパス解決の詳細は、それぞれの実装対象を直接読む。

## Read this when
- `cmoc oracle investigation` の TUI 起動条件、モデル・推論設定、ファイルアクセスモード、作業ディレクトリを確認するとき。
- oracle file 調査用の完全プロンプトに、ユーザー指示、調査範囲、目標、ルーティング規則などをどう組み込むか確認するとき。
- 完全プロンプトのログ保存から TUI 起動パラメータ返却までの流れを追跡するとき。

## Do not read this when
- 一般的な完全プロンプトの構築規則だけを確認する場合は、プロンプト構築の実装を直接読む。
- エージェント呼び出しパラメータの型や列挙値の定義だけを確認する場合は、ACP 基本型の定義を直接読む。
- リポジトリルートやエージェント作業パスの解決だけを確認する場合は、パスモデルの実装を直接読む。
