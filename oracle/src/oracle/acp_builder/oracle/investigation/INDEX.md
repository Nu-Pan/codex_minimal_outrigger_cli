# `launch_tui.py`

## Summary
- `cmoc oracle investigation` の TUI 起動用パラメータを構築する実装。oracle file 調査向けの固定プロンプトを生成・保存し、指定モデル、アクセスモード、作業ディレクトリ、インデックス事前処理を含む起動設定を返す。

## Read this when
- `cmoc oracle investigation` の TUI 起動条件、調査プロンプト、モデルやファイルアクセスモード、起動時のログ保存を変更・確認するとき。

## Do not read this when
- 他の cmoc コマンドの起動パラメータや、汎用プロンプト生成処理そのものを変更・確認するときは、該当する実装へ直接進む。
