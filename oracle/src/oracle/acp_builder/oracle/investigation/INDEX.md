# `launch_tui.py`

## Summary
- `cmoc oracle investigation` 用の完全プロンプトと、調査担当 TUI の起動パラメータを構築する入口。
- ユーザー指示を調査対象として組み込み、oracle 調査向けの読み取り専用設定、モデル、推論強度、起動作業ディレクトリ、インデックス事前処理をまとめて定義する。

## Read this when
- oracle investigation の調査起動を変更・確認するとき
- ユーザー指示から調査用の完全プロンプトと TUI 起動設定がどのように構成されるかを確認するとき

## Do not read this when
- 完全プロンプトの共通生成規則を確認したいときは、プロンプト構築側を直接読む
- ACP の基本パラメータ型やリポジトリパス解決の仕様を確認したいときは、それぞれの定義元を直接読む
