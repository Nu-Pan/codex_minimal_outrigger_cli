# `launch_tui.py`

## Summary
- `cmoc tui` サブコマンド用のプロンプトと TUI 起動パラメータを構築する定義。オリジナルプロンプトを埋め込んだ完全プロンプトを生成し、リポジトリ書き込み権限・作業ディレクトリ・モデル設定などを含む固定の `AgentCallParameter` を返す。

## Read this when
- `cmoc tui` の起動パラメータ、TUI に渡す完全プロンプト、またはオリジナルプロンプトの埋め込み方法を変更・確認するとき。
- TUI 呼び出しで使用するモデル、推論強度、ファイルアクセスモード、作業ディレクトリ、インデックス事前処理の設定を確認するとき。

## Do not read this when
- TUI 起動以外の AgentCallParameter 構築を扱うとき。
- 完全プロンプトの共通生成規則そのものを確認するときは、`build_complete_prompt` の定義を直接読むべき場合。
- CLI のサブコマンド解析や TUI の画面・対話処理を変更するとき。
