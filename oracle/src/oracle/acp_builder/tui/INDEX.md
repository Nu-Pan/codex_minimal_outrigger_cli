# `launch_tui.py`

## Summary
- `cmoc tui` の完全プロンプト生成と TUI 起動用 AgentCallParameter の構築を担う。オリジナルプロンプトを埋め込んだ作業指示を保存し、リポジトリを作業場所とする最高品質設定の TUI 起動パラメータを返すため、このサブコマンドの起動条件や prompt 文面を確認する入口となる。

## Read this when
- `cmoc tui` の起動パラメータ、使用モデル、推論設定、作業権限、作業ディレクトリを変更または確認するとき。
- TUI に渡す完全プロンプトの構築、保存先、またはオリジナルプロンプトの埋め込み方を変更または確認するとき。

## Do not read this when
- TUI 起動以外のサブコマンドのパラメータ構築を扱うときは、該当する起動定義を直接読む。
- プロンプト生成の共通仕様や個別の prompt builder の挙動だけを確認する場合は、共通実装を直接読む。
