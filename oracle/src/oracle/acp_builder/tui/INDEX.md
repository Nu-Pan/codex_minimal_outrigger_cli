# `launch_tui.py`

## Summary
- `cmoc tui` の起動時に使用する完全プロンプトと固定起動パラメータを構築する定義。リポジトリルートを作業ディレクトリとして確定し、オリジナルプロンプトを埋め込んだ prompt、最高性能モデル・最大推論設定、リポジトリ書き込み権限、インデックス事前実行などの TUI 用 AgentCallParameter を組み立てる。

## Read this when
- `cmoc tui` の起動パラメータ、TUI に渡す prompt 文面、またはオリジナルプロンプトの埋め込み方を変更・確認するとき。
- TUI 起動時のモデル、推論強度、ファイルアクセスモード、作業ディレクトリ、インデックス事前実行の設定を確認するとき。

## Do not read this when
- TUI 以外のサブコマンドの起動パラメータや、共通プロンプト生成処理そのものを直接確認・変更するときは、それぞれの対象定義へ進む。
- `AgentCallParameter` やパス解決、構造化文書レンダリングの共通仕様だけを確認する場合は、各共通モジュールを直接読む。
