# `launch_tui.py`

## Summary
- `cmoc tui` の起動に必要なエージェント呼び出しパラメータを構築する実装。リポジトリルートを作業ディレクトリとして確定し、オリジナルプロンプトから完全な指示文を生成・保存したうえで、最高性能・最大推論設定などの TUI 実行条件をまとめる。`cmoc tui` のプロンプト生成や起動設定の入口として扱う。

## Read this when
- `cmoc tui` の起動パラメータ、作業ディレクトリ、モデル設定、推論設定を変更または確認するとき。
- TUI に渡す完全プロンプトの生成・保存方法や、オリジナルプロンプトの埋め込み方を確認するとき。

## Do not read this when
- TUI 起動以外のサブコマンドのパラメータ構築を扱うとき。
- 完全プロンプトの共通構造そのものを変更・確認する場合は、まずプロンプト生成側の実装を読むべきとき。
