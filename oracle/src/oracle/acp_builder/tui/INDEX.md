# `launch_tui.py`

## Summary
- `cmoc tui` が AI Agent CLI/TUI を起動するための固定パラメータと完全プロンプトを構築する入口。オリジナルプロンプト、リポジトリ作業コンテキスト、アクセス・実行ポリシー、エディタ入力引き継ぎをまとめて起動設定へ変換する。

## Read this when
- `cmoc tui` の起動時に渡すプロンプト文面や Codex CLI の起動パラメータを変更・確認するとき。
- オリジナルプロンプトの埋め込み、リポジトリルートを基準にした作業コンテキスト、TUI 起動時のポリシー設定の組み立てを追跡するとき。

## Do not read this when
- TUI の画面表示・対話制御そのものを調べるとき。
- 完全プロンプトの共通生成規則だけを調べるときは、プロンプト生成側の定義を直接読む。
- 起動後の AI Agent 実行処理や個別サブコマンドの引数解析を調べるとき。
