# `launch_tui.py`

## Summary
- `cmoc tui` の TUI 起動に必要なプロンプトと `AgentCallParameter` を構築する定義。
- オリジナルプロンプトを埋め込んだ完全プロンプトを生成して所定のログへ保存し、リポジトリを作業ディレクトリとする起動条件を組み立てる。
- モデル、推論 effort、書き込み権限、インデックス事前処理など、TUI 実行時の固定設定を確認する入口となる。

## Read this when
- `cmoc tui` の起動パラメータや TUI 用の完全プロンプト生成処理を変更・確認するとき。
- TUI 起動時のモデル選択、推論 effort、作業ディレクトリ、ファイルアクセス権限、インデックス事前処理を確認するとき。
- ユーザー入力から完全プロンプトを生成し、起動用パラメータへ渡す流れを追うとき。

## Do not read this when
- TUI 以外のサブコマンドの起動パラメータを確認するとき。
- 完全プロンプトの共通生成規則そのものを確認するときは、共通の prompt builder 定義へ直接進む。
- パス解決や構造化文書の共通仕様だけを確認するときは、それぞれの共通定義へ直接進む。
