# `launch_tui.py`

## Summary
- `cmoc tui` サブコマンド向けの TUI 起動パラメータを構築する。オリジナルプロンプトから完全な作業プロンプトを生成・保存し、最高性能モデル・最大推論設定・リポジトリ書き込み権限などの固定起動条件を持つ `AgentCallParameter` を返す。

## Read this when
- `cmoc tui` の起動条件、モデルや推論設定、作業ディレクトリ、プロンプト保存先を変更・確認するとき。
- TUI 起動時に完全なプロンプトがどのように生成され、AI Agent CLI/TUI に渡されるかを確認するとき。

## Do not read this when
- TUI 以外のサブコマンドの起動パラメータを扱うとき。
- プロンプト本文の生成規則そのものを変更・確認するときは、プロンプト生成を担当する実装を直接読む。
- パス解決や構造化ドキュメントの一般的な仕様だけを確認するときは、それぞれの担当実装を直接読む。
