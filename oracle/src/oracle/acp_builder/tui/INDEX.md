# `launch_tui.py`

## Summary
- `cmoc tui` が受け取るオリジナルプロンプトを埋め込んだ完全プロンプトと、TUI 起動用の固定パラメータを構築する。
- リポジトリの作業コンテキスト、書き込み権限、プロンプト内の oracle・realization・routing 規則、エディタ入力引き継ぎを起動設定へ反映する。
- TUI 起動時の agent call 設定とインデックス事前処理の入口となる。

## Read this when
- `cmoc tui` の TUI 起動パラメータを変更・調査するとき。
- オリジナルプロンプトから完全プロンプトを構築する経路を確認するとき。
- TUI 起動時に渡す作業ディレクトリ、ファイルアクセスモード、エディタ入力引き継ぎ、インデックス事前処理を確認するとき。

## Do not read this when
- 完全プロンプトの一般的なレンダリング規則だけを確認したいときは、プロンプト生成側を直接読む。
- エージェント呼び出しパラメータの型やアクセスモードの定義だけを確認したいときは、ACP 基本定義側を直接読む。
