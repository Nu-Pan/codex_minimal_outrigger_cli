# `launch_tui.py`

## Summary
- `cmoc tui` の起動に使う固定パラメータと、ユーザー入力を埋め込んだ完全プロンプトを構築する入口。
- TUI 起動時のリポジトリ書き込み権限、作業ディレクトリ、エディター入力引き継ぎ、インデックス事前処理の設定を確認する対象。

## Read this when
- `cmoc tui` の起動パラメータを変更または調査するとき。
- オリジナルプロンプトを完全プロンプトへ埋め込む処理や、TUI 起動時に適用するポリシーを確認するとき。
- TUI 起動時の作業ディレクトリ、ファイルアクセスモード、エディター入力引き継ぎ、インデックス事前処理の設定を確認するとき。

## Do not read this when
- 完全プロンプトの共通構造そのものを変更するときは、まず完全プロンプト構築側の定義を読むとき。
- TUI 以外の agent call の起動パラメータだけを調査するとき。
