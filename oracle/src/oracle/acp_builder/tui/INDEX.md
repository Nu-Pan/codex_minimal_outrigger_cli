# `launch_tui.py`

## Summary
- `cmoc tui` の TUI 起動用 `AgentCallParameter` を構築する正本ソース。オリジナルプロンプトから完全な動的プロンプトを生成・保存し、最高性能モデル、最大推論、リポジトリ書き込み、インデックス事前処理などの起動設定をまとめて返す。TUI 起動条件や prompt 生成、agent call パラメータの変更を調べる際の入口。

## Read this when
- `cmoc tui` の TUI 起動処理を変更・調査するとき
- 完全なプロンプトの生成・保存先やオリジナルプロンプトの組み込み方を確認するとき
- TUI 用のモデル、推論強度、ファイルアクセスモード、作業ディレクトリ、構造化出力設定を確認するとき

## Do not read this when
- TUI 以外のサブコマンドの起動パラメータを調べるとき
- 完全なプロンプトの共通生成仕様だけを確認したいときは、prompt builder の実装を直接読む
- TUI の実行本体や画面操作の挙動だけを調べるとき
