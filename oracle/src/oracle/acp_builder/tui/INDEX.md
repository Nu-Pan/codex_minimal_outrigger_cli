# `launch_tui.py`

## Summary
- `cmoc tui` サブコマンドが AI Agent CLI/TUI を起動するための固定パラメータと完全プロンプトを構築する定義。オリジナルプロンプトを埋め込み、リポジトリ作業用のパス・権限・oracle/realization・ルーティング方針を設定する処理の入口。

## Read this when
- `cmoc tui` の起動パラメータ、モデル・推論設定、作業ディレクトリ、ファイルアクセス権限、または TUI 用完全プロンプトの構築を変更・確認するとき。
- TUI 起動時に渡すプロンプトへ、構造化された補助情報やリポジトリ固有の作業方針を組み込む経路を追跡するとき。

## Do not read this when
- TUI 起動パラメータの構築ではなく、完全プロンプトの共通生成ロジック自体を変更・確認する場合は、先にその生成処理の定義を読む。
- `cmoc tui` 以外のサブコマンドや、TUI 実行後の対話・エージェント処理を調べる場合は、各機能の直接の実装へ進む。
