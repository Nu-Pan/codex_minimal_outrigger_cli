# `launch_tui.py`

## Summary
- `cmoc tui` 用の Codex CLI TUI 起動パラメータを構築する定義。ユーザーのオリジナルプロンプトと確定済みのエディタ入力引き渡し元を完全プロンプトへ組み込み、リポジトリ書き込み権限、作業ディレクトリ、入力引き渡し MCP、索引付け前処理などの起動設定をまとめて返す。

## Read this when
- `cmoc tui` がどのプロンプト構成と起動パラメータで TUI を開始するか確認したいとき
- オリジナルプロンプト、エディタ入力引き渡し元、リポジトリのパスコンテキストが TUI 起動時にどう組み込まれるか確認したいとき
- TUI 起動時の固定設定（書き込みモード、作業ディレクトリ、入力引き渡し MCP、索引付け前処理）を変更・検証するとき

## Do not read this when
- TUI の画面表示や対話部品そのものの実装を確認したいときは、TUI 内部の対象を直接読む
- 完全プロンプトの共通構成規則だけを確認したいときは、プロンプトビルダーの対象を直接読む
- エディタ入力引き渡しの型や送信元情報の定義だけを確認したいときは、`EditorInputHandoffSource` の定義を直接読む
