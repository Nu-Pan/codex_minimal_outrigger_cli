# `launch_tui.py`

## Summary
- `cmoc tui` がユーザー入力を埋め込んだ完全プロンプトと、TUI 起動に必要な固定パラメータを構築する定義。
- プロンプトにはリポジトリ書き込み権限、リポジトリを作業ディレクトリとするパス文脈、oracle・realization・ルーティング関連の規則が組み込まれる。

## Read this when
- `cmoc tui` の起動時に、ユーザーのオリジナルプロンプトがどのように完全プロンプトへ組み込まれるか確認したいとき。
- TUI 起動パラメータの作業ディレクトリ、権限、エージェント呼び出し種別、インデックス前処理の設定を確認したいとき。

## Do not read this when
- 完全プロンプトを構成する共通ビルダーの詳細や SD ノードの Markdown レンダリング仕様を直接確認したいとき。
- `cmoc tui` のサブコマンド呼び出し側の引数処理や、TUI 自体の画面・実行制御を調べたいとき。
