# `launch_tui.py`

## Summary
- `cmoc tui` 用の完全プロンプトと Codex CLI TUI 起動パラメータを構築する定義。
- ユーザー入力を動的プロンプトへ組み込み、リポジトリ書き込み権限・エディタ入力引き渡し・インデックス事前処理などの起動条件を固定する。

## Read this when
- `cmoc tui` のエージェント呼び出しプロンプトや起動パラメータを変更・確認するとき
- TUI 起動時のパスコンテキスト、ファイルアクセスモード、動的プロンプト、事前処理の設定を調査するとき

## Do not read this when
- TUI 起動パラメータではなく、別の ACP 呼び出し種別や個別のプロンプト構築処理だけを調査するとき
- 呼び出し後の TUI 実行処理や、対象関数が利用する共通ビルダーの実装を直接確認したいとき
