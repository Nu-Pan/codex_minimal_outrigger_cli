# `launch_tui.py`

## Summary
- `cmoc tui` の対話起動に使用する固定パラメータを、入力プロンプトから構築する関数を定義する。
- オリジナルプロンプトを埋め込んだ完全プロンプトを生成し、リポジトリ書き込み権限、リポジトリルートを基準とする作業場所、最高品質モデル、最大推論、インデックス事前処理などの TUI 起動設定をまとめて返す。
- TUI 起動パラメータの内容、プロンプト構築、または `cmoc tui` の起動前処理を確認・変更するときの入口となる。

## Read this when
- `cmoc tui` が AI Agent CLI/TUI に渡すプロンプトや起動パラメータを調査するとき
- TUI 用のモデル設定、推論設定、ファイルアクセスモード、作業ディレクトリ、インデックス事前処理を変更するとき
- 完全プロンプトの skeleton と実行時構築で共有される構築経路を確認するとき

## Do not read this when
- TUI 以外のサブコマンドの起動パラメータを調査するとき
- 完全プロンプトの共通生成規則そのものを変更・確認するときは、プロンプト構築側の定義を直接読むとき
- TUI の画面表示や入力編集の実装を調査するときは、該当する UI 実装を直接読むとき
