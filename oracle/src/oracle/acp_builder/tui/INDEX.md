# `launch_tui.py`

## Summary
- `cmoc tui` の TUI 起動用 `AgentCallParameter` を構築する正本実装。元のユーザープロンプトを完全プロンプトへ埋め込み、保存先・作業ディレクトリ・モデル・推論強度・アクセスモードなどの起動条件を固定する。

## Read this when
- `cmoc tui` の起動パラメータ、TUI 用プロンプト生成、エディタ入力の保存、TUI 呼び出し時のモデルや作業ディレクトリ設定を確認・変更するとき。

## Do not read this when
- TUI 以外のサブコマンドや起動方式のパラメータを調べるとき。
- 完全プロンプトの共通構造やレンダリング仕様だけを調べるときは、プロンプト生成側の実装を直接読む。
