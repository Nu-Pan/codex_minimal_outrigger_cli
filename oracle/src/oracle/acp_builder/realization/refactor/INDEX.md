# `fork`

## Summary
- 変更差分を意味論的カテゴリ別に整理する構造化出力スキーマで、変更カテゴリ・概要・根拠ファイルを確認するための入口です。
- refactor fork の変更差分を人間向けに要約する AgentCallParameter の正本実装で、要約用 prompt と実行条件の構築経路を確認できます。
- ファイル単位のレビュー・修正処理の結果を表す構造化出力スキーマで、所見の根拠、変更対象、正本仕様との関係、対応状況を確認するための入口です。
- realization refactor fork のファイル単位レビュー・修正用 AgentCallParameter を構築する正本実装で、対象パス、アクセス規則、モデル設定、構造化出力、事前インデックス処理を確認できます。

## Read this when
- 変更内容をカテゴリ別に要約する出力形式や必須項目を確認するときは、変更要約スキーマを読む。
- refactor fork の変更差分を要約する prompt 構築処理や AgentCallParameter の実行条件を変更・調査するときは、変更要約実装を読む。
- レビュー・修正結果の出力契約、所見の根拠、変更パス、対応状態を確認するときは、レビュー・修正スキーマを読む。
- realization refactor fork のファイル単位レビュー・修正呼び出し、対象パス解決、アクセス権、モデル設定、スキーマ設定、完全 prompt の構築経路を変更・調査するときは、レビュー・修正実装を読む。

## Do not read this when
- 変更差分の要約ロジック自体を調査するときは、変更要約スキーマではなく変更要約実装を読む。
- 変更内容そのものや要約結果の形式だけを確認するときは、変更要約実装ではなく差分入力元または対応するスキーマを読む。
- レビュー対象の実装内容や個別仕様を調査するときは、レビュー・修正スキーマではなく対象ファイルと対応する oracle file を直接読む。
- 構造化出力のフィールド定義だけを確認するときは、レビュー・修正実装ではなく専用 JSON スキーマを読む。
- fork 以外の agent call 種別の prompt 生成を調査するときは、レビュー・修正実装を読まない。
