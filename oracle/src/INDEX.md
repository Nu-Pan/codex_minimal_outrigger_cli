# `oracle`

## Summary
- cmoc がエージェントへ渡す呼び出しパラメータやプロンプトを定義し、oracle 調査・編集、realization の追従・整理、競合解消、feedback、索引生成などのワークフロー別の構築元をまとめています。
- 共通プロンプト規定と文書レンダリング、パス・設定・文書参照のモデル、およびエディタ入力の引き渡し文面を扱います。

## Read this when
- cmoc がエージェントへ渡す指示やアクセス規定の構成を変更・調査するとき。
- 特定ワークフローのエージェント呼び出しや、エディタ入力の引き渡し文面の構築元をたどるとき。
- 複数ワークフローで共有するパス、設定、文書参照、構造化文書のモデルやレンダリングを変更するとき。

## Do not read this when
- 指示やコマンドの意味仕様・優先関係を確認するときは、該当する oracle doc を直接読む。
- 単一ワークフローの呼び出し定義や出力契約だけを変更するときは、そのワークフローの定義へ直接進む。
- CLI の実行手順や実行時挙動、テストだけを調べるときは、それらを所有する実装やテストへ直接進む。
