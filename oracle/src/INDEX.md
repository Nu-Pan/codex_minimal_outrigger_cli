# `oracle`

## Summary
- エージェントへ渡す共通指示文とタスク別の呼び出し内容を組み立てるソース群で、エディターへの引き継ぎやフィードバック対応の文面も定義する。
- 呼び出しで共有するパス文脈、設定、文書構造・参照、文書検索のモデルも扱う。

## Read this when
- 複数のエージェント呼び出しにまたがって、共通指示文の選択・構成方法やタスク固有情報の渡し方を調べるとき。
- oracle の調査・編集、realization の追従、変更の統合、フィードバック対応などの呼び出し内容を横断して確認するとき。
- パス解決、設定、文書参照、文書検索に関わる共有モデルを調べるとき。

## Do not read this when
- 調査対象が単一のタスク領域や構成要素に絞られており、専用の下位エントリーがあるときは、そちらを起点にする。
- 生成された呼び出しの実行時動作や回帰を調べるときは、対応する実装またはテストを起点にする。
