# `oracle`

## Summary
- AIエージェント呼び出しの論理パラメータ型を定義する正本ソース、プロンプト構築の正本ソース、設定・パス・規範・構造化文書を扱う正本ソースを収録する領域。呼び出し条件やプロンプト生成の責務ごとに下位ディレクトリを選ぶ入口となる。

## Read this when
- AIエージェント呼び出しのモデル種別、推論強度、ファイルアクセスモード、呼び出しパラメータを確認するとき。
- root placeholder を含むパス解決、agent call ごとのパスコンテキスト、設定値や oracle review 設定を確認するとき。
- 規範や要件の構造化、StructDoc の Markdown 化、cmoc_ref 検証を確認するとき。
- oracle・realization・レビュー・ファイルアクセス・INDEX ルーティングなどをプロンプトへ組み込む処理を確認するとき。
- ユーザー入力用プロンプトの初期案内文を確認するとき。

## Do not read this when
- 個別サブコマンドの実行フローや、CLI からこれらの正本ソースを利用する処理だけを確認したいとき。
- 特定の oracle 文書や realization 実装そのものの内容を確認したいとき。
- 下位ディレクトリ内の特定責務が明らかな場合は、この領域を横断的に読む必要はなく、該当する下位ディレクトリへ直接進むとき。
