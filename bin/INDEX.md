# `cmoc`

- cmoc の起動用シェルラッパー。プロジェクトルートを解決し、仮想環境の Python 実行可能性を検査したうえで CLI の Python エントリーポイントへ引数を渡す。通常起動時の仮想環境不足エラーと、補完プローブ時の簡略的な失敗経路を扱う。
- cmoc の起動方法、仮想環境 Python の検証、起動前エラー報告、シェルラッパーから Python CLI への委譲を確認するための入口。実際の CLI 挙動やエラー仕様の詳細を調べる場合は、委譲先の Python 実装や参照コメントに示された仕様文書へ進む。
