# `cmoc`

## Summary
- cmoc の CLI 起動ラッパー。プロジェクトの仮想環境 Python を検証し、通常実行時は `src/main.py` へ引数を渡す。補完プローブ時は仮想環境が利用可能な場合だけ同じ入口を実行する。仮想環境が利用できない場合は、セットアップ手順と呼び出し箇所を含むエラーを表示する。

## Read this when
- cmoc コマンドの起動経路、仮想環境 Python の検証、補完プローブ時の挙動、または起動失敗時のエラー表示を確認するとき。

## Do not read this when
- CLI サブコマンドの実装や引数処理そのものを調べるときは、直接 `src/main.py` と該当する実装を読む。
- 開発環境の正本仕様やセットアップ規則を確認するときは、対応する oracle ドキュメントを直接読む。
